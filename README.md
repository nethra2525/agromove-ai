# AgriMove

AgriMove is a smart agriculture transportation web application developed to help farmers transport produce from remote farms to the nearest motorable road.

## Features
- Real-time GPS tracking
- Battery monitoring
- Cart status updates
- Weight monitoring
- Temperature monitoring
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase
